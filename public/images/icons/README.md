# PWA Icons

Place your app icons here in the following sizes:

| File              | Size    | Used for                        |
|-------------------|---------|---------------------------------|
| icon-72x72.png    | 72×72   | Android legacy                  |
| icon-96x96.png    | 96×96   | Android / shortcut icons        |
| icon-128x128.png  | 128×128 | Chrome Web Store                |
| icon-144x144.png  | 144×144 | Windows tile / Android          |
| icon-152x152.png  | 152×152 | iPad home screen (iOS)          |
| icon-192x192.png  | 192×192 | Android home screen (required)  |
| icon-384x384.png  | 384×384 | Android splash screen           |
| icon-512x512.png  | 512×512 | Android splash / PWA (required) |

## Quick way to generate all sizes

Use the free tool at https://www.pwabuilder.com/imageGenerator
or https://realfavicongenerator.net/

Just upload your highest-resolution logo (ideally 512×512 or larger)
and download the generated icon pack. Then drop the files in this folder.

The two most critical sizes are **192×192** and **512×512** — Chrome
requires both for the install prompt to appear.
